
Phase 1 Testing Checklist
====================================================
1. Multi-Tenant Security
-----------------------------------
- Admin A cannot see School B students
- Admin A cannot see School B employees
- Admin A cannot see School B classes
- Admin A cannot see School B academic records
This is the most important test in CampusIQ.

2. Role-Based Access Control (RBAC)
----------------------------------
Role	            Access
SUPER_ADMIN	        All Schools
SCHOOL_ADMIN	    Own School Only

Exit Criteria for Phase 1
Move to Phase 2 only after:
✅ Migrations clean
✅ No duplicate data issues
✅ RBAC working
✅ School isolation working
✅ Employee flow working
✅ Student flow working
✅ Teacher assignment working
✅ Admin screens usable

Once these pass, Phase 2 (Timetable + Attendance) will be much smoother because it will build on a stable foundation.
